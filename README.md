# Le petit jardin de Ghita

Site indépendant pour découvrir en jouant vers 3 ans, avec un adulte.

12 jeux : couleurs, formes, animaux, premiers nombres de 1 à 3, mémoire (3 paires), bulles, tailles, fruits, suites visuelles, piano pentatonique, mosaïque colorée et jardin à faire pousser.

Consignes vocales via la synthèse vocale du navigateur (français si disponible), commande de son, cibles tactiles larges, aucun chronomètre ni pénalité. Les fleurs de découverte restent dans le navigateur de l’appareil. La peinture est temporaire et recommence à chaque ouverture du jeu.

Aucun compte, publicité ou service de mesure d’audience. Les polices Google sont facultatives et possèdent des polices de secours. Les emojis varient selon l’appareil. La synthèse vocale et les notes peuvent être indisponibles selon le navigateur.

Déploiement GitHub Pages de `public/` avec le workflow fourni. Les sites de Douaa restent indépendants.
